# Ledgerline

- Look for and use the relevant official Firebase agent skills before making Firebase changes. Use Firebase Authentication skills for identity and the Firebase Basics skill for project or web app registration.
- Use the Neon and Neon Postgres skills for database setup, schema changes, and migrations. Keep Firebase as the identity provider and Neon Postgres as the application database.
- Keep database connection strings and service credentials in local environment files or the deployment environment. Run database migrations from `database/migrations/`.
